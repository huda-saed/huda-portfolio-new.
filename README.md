## ⚙️ Customization

The portfolio content can be updated through `js/config.js`.

- **Education:** Update your academic information.
- **Projects:** Add new projects and screenshots.
- **Certificates:** Add certificates and verification links.
- **Contact:** Update your social media and contact information.
- **Profile:** Update your personal details and introduction.

## 🌐 Deployment

This portfolio is a static website built with HTML, CSS, and JavaScript. It requires no build tools or external dependencies.

It can be deployed using **GitHub Pages**:

1. Push the project files to the `main` branch.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save your settings.
